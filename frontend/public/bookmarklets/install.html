Installer le sync LinkedIn

Un favori dans ta barre Chrome = 1 clic pour synchroniser tes connexions LinkedIn avec El Prospector.

1Affiche ta barre de favoris

Si elle n'est pas visible, appuie Cmd + Shift + B.

2Drag-and-drop UN des boutons ci-dessous dans ta barre de favoris

Choisis selon ton besoin. Glisse le bouton dans la barre.

Mode minimal recommande

Aucun panel dans LinkedIn. Scrape + alert + copie dans presse-papier. Robuste, blinde contre CSP / interferences LinkedIn.

Sync LinkedIn (minimal)
Mode explore (avec UI)

Affiche un panel dans LinkedIn avec les resultats. Plus joli mais peut planter si LinkedIn interfere avec l'injection HTML.

Sync LinkedIn (explore) debug

3Utilise-le sur LinkedIn

  1. Va sur linkedin.com/mynetwork/invite-connect/connections/
  2. Clique le favori "Sync LinkedIn (explore)" dans ta barre
  3. Laisse-le scroller tes connexions (10-30 sec selon la quantite)
  4. Un panel apparait en haut a droite avec le resultat + un bouton "Copier JSON"
  5. Copie et envoie-moi le JSON pour qu'on valide les selecteurs
